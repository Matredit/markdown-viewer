💡 Why do agent outputs need special handling?
AI agents regularly generate complex GitHub Flavored Markdown (GFM): pipes in tables, task checkboxes (- [x]), syntax-highlighted code blocks, and mermaid architecture diagrams. While lightweight parsers like snarkdown are tiny (2KB), they lack table and task support. Marked and markdown-it provide the ideal combination of speed and standard compliance for agent workflows.
